# 오늘의 아침 등교 미션!

학교에 가기 전 해야 할 일을 하나씩 확인하고, 오늘 날씨에 맞는 옷차림도 살펴볼 수 있는 페이지입니다.

## 이렇게 사용해요

1. https://loekohc.github.io/Morning_check/ 페이지를 브라우저에서 엽니다.
2. 날씨와 옷차림 추천을 확인합니다. 내 위치의 날씨를 보려면 위치 접근을 허용해 주세요.
3. 준비를 마친 미션 카드를 눌러 완료 표시를 합니다.
4. 모든 미션을 마치면 축하 화면이 나타납니다.

## 아침 미션

- 필통 챙기기
- 물통 챙기기
- 아침 밥 먹기
- 양치하고 세수하기
- 옷 입기
- 방과후 준비물 챙기기

곰과 토끼 중 원하는 캐릭터를 고를 수 있고, 소리 안내를 켜거나 끌 수도 있습니다. 완료한 미션은 오늘 날짜 기준으로 사용 중인 기기에 저장됩니다.

실시간 날씨를 확인하려면 인터넷 연결이 필요합니다. 위치 정보를 사용할 수 없으면 서울 날씨를 기준으로 보여줍니다.
